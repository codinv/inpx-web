# inpx-web

***Веб-сервер для поиска по .inpx-коллекции книг.***

Более подробно у автора проекта [bookpauk/inpx-web](https://github.com/bookpauk/inpx-web)

Приложение собрано из исходников [makss/inpx-web](https://github.com/makss/inpx-web) forked from [bookpauk/inpx-web](https://github.com/bookpauk/inpx-web)

Данная сборка позволяет подключать внешние программы (конвертеры, читалки, экспорт). [подробнее тут](https://github.com/makss/inpx-web/tree/feature_external?tab=readme-ov-file#%D0%BF%D0%BE%D0%B4%D0%BA%D0%BB%D1%8E%D1%87%D0%B5%D0%BD%D0%B8%D0%B5-%D0%B2%D0%BD%D0%B5%D1%88%D0%BD%D0%B8%D1%85-%D0%BF%D1%80%D0%BE%D0%B3%D1%80%D0%B0%D0%BC%D0%BC-%D0%BA%D0%BE%D0%BD%D0%B2%D0%B5%D1%80%D1%82%D0%B5%D1%80%D1%8B-%D1%87%D0%B8%D1%82%D0%B0%D0%BB%D0%BA%D0%B8-%D1%8D%D0%BA%D1%81%D0%BF%D0%BE%D1%80%D1%82)

#### 📦 Используемые утилиты:

- 📖 **[fb2cng (fbc)](https://github.com/rupor-github/fb2cng)** — конвертация FB2 в EPUB3
- ✉️ **[sync2kindle (s2k)](https://github.com/rupor-github/sync2kindle)** — отправка книг на Kindle по email

## 🐳 Запуск с помощью Docker Compose
( пример [docker-compose.yaml](https://github.com/codinv/inpx-web/blob/main/examples/docker-compose.yaml) )

```yaml
services:
  server:
    container_name: inpx-web
    image: ghcr.io/codinv/inpx-web
    network_mode: bridge
    ports:
      - "12380:12380/tcp"
    restart: unless-stopped
    environment:
      TZ: Europe/Moscow
      LIB_DIR: /library/lib.rus.ec
      INPX_FILE: /library/librusec_local_fb2.inpx
    volumes:
      - ./:/data
      - /volume1/MyLibrary:/library:ro
```

> Параметры в **<span style="color:green">environment:</span>** \
<span style="color:red">**LIB_DIR**</span> : полный путь к папке с архивами книг внутри контейнера \
> всегда начинается с <span style="color:red">**/library**</span>, так как именно в эту папку монтируется ваша библиотека через `volumes:` \
<span style="color:red">**INPX_FILE**</span> : полный путь к INPX файлу в docker контейнере: \
так же всегда должен начинаться с <span style="color:red">**/library**</span>, если файл дополнительно не подключен через **<span style="color:green">volumes</span>**

в данном примере используется следующая структура:

```
📁 volume1/
└── 📂 MyLibrary/
    ├── 📄 librusec_local_fb2.inpx         # Основной INPX-файл
    └── 📂 lib.rus.ec/                     # Основное хранилище книг c fb2-архивами
        ├── 📦 fb2-000001-010000.zip
        ├── 📦 fb2-010001-020000.zip
        └── 📦 fb2-020001-030000.zip
```

## Использование

После первого запуска контейнера в папке с приложением автоматически создастся директория `config-examples`, содержащая примеры конфигурационных файлов.

### Первоначальная настройка

Для корректной работы приложения необходимо переместить и настроить файлы из папки `config-examples`:

1. **`external_tools.json`** — файл конфигурации внешних утилит.
   - Отредактируйте его под свои требования и скопируйте в **корневую папку с данными** (на уровень выше).

2. **`fbc-config.yaml`** — файл настроек конвертера **fb2cng**.
   - При необходимости отредактируйте параметры конвертации и скопируйте файл в папку `./app-fb2cng`.

3. **`s2km-config.yaml`** — файл настроек приложения **sync2kindle** для отправки книг на почту.
   - Отредактируйте файл, указав свои данные: **адрес электронной почты**, **пароль приложения** для почты, **настройки SMTP-сервера** и **адрес электронной почты Kindle**. Сохраните готовый файл в папку `./app-sync2kindle`.

4. **`worker.sh`** — скрипт для автоматизации процессов конвертации и отправки книг на почту.
   - Скопируйте этот скрипт в **корневую папку с данными** (на уровень выше).

### Завершение настройки

После того как все файлы настроены и размещены в соответствующих папках, **перезапустите Docker-контейнер**, чтобы применить изменения.

## Обновление утилит

Утилиты **fb2cng** (`app-fb2cng/fbc`) и **sync2kindle** (`app-sync2kindle/s2km`) обновляются вместе с образом.
Рядом с каждой из них лежит файл с номером версии (`fbc.ver`, `s2km.ver`). При запуске контейнера версия в образе сравнивается с установленной,
и если они отличаются, утилита заменяется, а прежняя копия сохраняется рядом как `fbc.bak` / `s2km.bak`.
Ваши конфиги (`fbc-config.yaml`, `s2km-config.yaml` и другие) при этом не затрагиваются.

```bash
docker compose pull && docker compose up -d
```

В логе контейнера видно, что произошло: строки вида `[init] app-fb2cng/fbc: v1.8.0 -> v1.9.0`.

### Не хочу обновлять утилиту: отключить обновление

Создайте рядом с ней пустой файл `*.pin`: утилита и её файл версии больше не будут перезаписываться.

```bash
touch app-fb2cng/fbc.pin          # закрепить fb2cng
touch app-sync2kindle/s2km.pin    # закрепить sync2kindle
```

Чтобы снова получать обновления, удалите `*.pin`. 
Свою версию утилиты можно положить вручную: замените бинарник и создайте `*.pin`.

### Новая версия работает хуже: откат

```bash
cd app-fb2cng
mv fbc.bak fbc
mv fbc.ver.bak fbc.ver
touch fbc.pin
```

Если `fbc.ver.bak` нет (обновление с очень старого образа), этот файл пропустите. Откат работает только на одну версию назад, потому что `.bak` перезаписывается при следующем обновлении.

> При первом запуске нового образа поверх старой установки (без файлов `.ver`) обе утилиты будут обновлены один раз, старые версии останутся в `.bak`.
> Если вы заменяли бинарники вручную, создайте `.pin` до запуска.

### Примеры конфигов

Содержимое `config-examples` обновляется при каждом старте контейнера. Не редактируйте файлы там, копируйте их в нужную папку (см. выше).

`inpx-web` (`app-inpx-web/inpx-web`) в образе статический и не обновляется.

## Скрипт автоматизации
( [worker.sh](https://github.com/codinv/inpx-web/blob/main/examples/worker.sh) )

### Скрипт выполняет следующие действия:

1. Конвертирует FB2-книгу в EPUB3 с помощью fb2cng

2. Формирует имя файла в формате `Фамилия И. - Название`
   - Автор: фамилия + инициалы (первая буква имени и отчества)
   - Разделитель: ` - `
   - Название очищается от символов: `/\:*?<>"` и кавычек `«»“”„`
   - Удаляются квадратные скобки `[...]` и лишние пробелы

3. Формирует внутренний заголовок книги (метаданные) в формате `XX. Название`
   - Если у книги есть серия с номером — добавляется префикс `XX.` 
   - Если серий несколько — берётся первая, у которой есть номер
   - Если номера нет — префикс не добавляется
   - Название очищается от кавычек, скобок и лишних пробелов

4. Сохраняет готовый EPUB-файл в папку `/app-export`

5. Отправляет на почту Kindle готовый EPUB-файл с помощью sync2kindle

6. Очищает временные папки
